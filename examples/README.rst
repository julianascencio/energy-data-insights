Example gallery
===============

Downloadable Python examples run during every documentation build without API
credentials or live downloads. Most use synthetic inputs or offline request
planning; the worldwide KGPV example uses an attributed NOAA climatology, and
the soiling/snow maps use NASA POWER and ERA5-Land inputs. Each example
identifies its inputs and limitations. Figures do not
represent observed plant performance or validated projections.

For the full thesis-style CCYA report workflow, see
:doc:`the applied case guide </_generated/studies/ccya>`.
