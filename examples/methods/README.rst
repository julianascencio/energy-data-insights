Methods
========

Learn the reusable calculations in ``energy_methods`` with small, synthetic
inputs: climate-change yield assessment (CCYA), typical daily profiles and
Köppen-Geiger-Photovoltaic (KGPV) classification. Each tutorial explains the
meaning of its outputs and links to the relevant scientific guide.

For applications to attributed climate datasets, continue to
:doc:`Analysis </auto_examples/analysis/index>`.
