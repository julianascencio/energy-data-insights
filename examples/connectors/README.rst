Connectors
==========

Retrieve and interpret weather and generation data with
``energy_data_retrieval``. The AEMO, U.S. EIA and Spain REE examples read captured
public observations with provenance and checksums. ERA5 and Europe ENTSO-E
demonstrate offline request planning; the ENTSO-E example also includes an
explicit opt-in path for credentialed downloads.

Download the :download:`four generation examples with their data
</auto_examples/connectors/generation_examples.zip>` to run them from an extracted folder.
See the
:doc:`generation connector guide </_generated/guides/generation-connectors>`
for provider access, units, coverage and timestamp conventions.
