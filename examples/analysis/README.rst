Analysis
========

Follow applied workflows from attributed climate inputs through scientific
methods to maps and area summaries. These worldwide examples use captured NOAA,
NASA POWER and ERA5-Land data, so the gallery runs offline. Each study documents
its spatial resolution, time coverage and interpretation limits.

For longer studies with configurable inputs and reports, see the
:doc:`CCYA case guide </_generated/studies/ccya>` and
:doc:`degradation study guide </_generated/studies/degradation>`.
