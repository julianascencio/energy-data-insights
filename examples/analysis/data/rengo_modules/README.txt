rengo_study.json preserves exact requests, capture dates, source metadata,
SHA-256 checksums, inspection scope and counting parameters. Source metadata
at one point report 2024-01-14 / 0.31 m; this does not guarantee the whole scene.
The slightly oversampled RGB render has not been sharpened or generated.

visual_annotations.json is a small single-assistant visual interpretation,
not independently verified ground truth. initial_visual_annotations.json
preserves the original rough clicks before correction of seam/centre mistakes.
The corrected file explains the revision and its exploratory status.
A shadowed support gap is omitted from scoring. Missing detections are reported.

The candidate inventory covers only a southern inspection block. It is not a
verified count of the whole farm, an electrical capacity estimate or a survey.
