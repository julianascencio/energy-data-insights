## Canadian bounded inventory review

The original workbook SHA-256 and byte count are in
`2026-11-03-top10-source-review.json`; raw workbook bytes are not committed.
The portal update date is not a current-operation date.

All 7,841 source rows were grouped by province and project name, producing 327
candidate groups. A deliberately limited normalized-name screen found 145 groups
with candidate links to existing records and 182 without matches. Neither result
establishes identity or confirms a new farm. The complete 327-group ledger retains
Excel row locators, all reported project-capacity values and tentative record IDs.

There are 7,758 distinct turbine identifiers. 82 identifier values repeat across
165 rows; the review JSON preserves every affected row and project name. Resolve
these before importing turbine children. Do not sum repeated project capacity on
turbine rows, or substitute turbine count times rating for reported capacity.

Unmatched-name examples include Buffalo Plains, Bekevar, Jenner Wind, Sharp Hills,
Windrise, Whitla Wind and Forty Mile Bow Island - Phase 1. Older farms with changed
names also occur, so 182 must not be presented as the number of new projects.
